# PT. Mahkota Baru Isolasi — website

A modern, responsive rebuild of https://mahkotabaruisolasi.co.id with the same content
(products, prices, services, contact details, vision & mission). Bahasa Indonesia.

Plain static HTML/CSS/JS, generated by a small Node script — no framework, no dependencies.

## Run

```bash
npm run build     # generates ./dist
npm run serve     # build + serve on http://localhost:8080
```

Upload the contents of `dist/` to any static host (cPanel, Netlify, Vercel, GitHub Pages, S3…).

## Where to edit content

| What | File |
|---|---|
| Company info, address, WhatsApp, email, nav menu, home page text, vision & mission | `src/data/site.mjs` |
| Products (name, price, description, photo) | `src/data/products.mjs` |
| Service pages (Jasa, Asuransi, Konsultan, Manajemen, Konsuler, Terjemahan) | `src/data/services.mjs` |
| Styles / colors | `src/assets/css/style.css` (CSS variables at the top) |
| Interactions (slider, search, filters, modal, mobile menu) | `src/assets/js/main.js` |
| Page templates | `build.mjs` |

To add a product: put the photo in `src/images/storage/app/public/produk_foto/` and add a line
`['file.jpg', 'Product name', 123000, 'Description']` to the right category in `products.mjs`. Then run `npm run build`.

## AI chatbot link

Every page has an "Asisten AI" button to the left of the WhatsApp button. While the chatbot
(`mova-ecommerce-mahkotabaruisolasi-chatbot-server`) is not installed, the button is grey and not clickable
("segera hadir"). Once the chatbot is online, build with its address and the button turns blue and opens the
chat in a new tab:

```bash
CHATBOT_URL=https://your-chatbot-host/ npm run build
```

## Icons & social share image

`src/images/brand/` holds the favicons, app icons and the 1200×630 share image (`og-image.jpg`)
used by Facebook, LinkedIn, WhatsApp and X. Regenerate them with `python3 scripts/make-icons.py`
(needs Pillow). After changing the share image, bump `OG_VERSION` in `build.mjs`, then re-scrape
the page in the [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) and
[LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/) so they drop their cached copy.

## Features

- Hero slideshow, service cards, featured products (tabs), vision/mission, contact + Google Map
- Product catalogues (`isolasi.html`, `insulasi.html`): sticky category bar, live filter, product detail modal with a "Pesan via WhatsApp" button that pre-fills the message with the product name and price
- Global search (header button, or `/` / `Ctrl+K`) across all products and services
- Pre-filled WhatsApp links on every service page, plus a floating WhatsApp button
- Mobile drawer menu, accessible dropdowns, reduced-motion support, sitemap.xml and robots.txt

## Notes

- URLs use `.html` (e.g. `/isolasi.html`) where the old site used `/isolasi`. Enable "clean URLs"
  on your host, or add redirects from the old paths.
- The old site's language switcher (EN/DE) wasn't carried over, because only the Indonesian content was copied.

## Company profile (PDF)

`company-profile/` holds the company profile in Bahasa Indonesia (A4, 12 pages):
[`Company-Profile-PT-Mahkota-Baru-Isolasi.pdf`](company-profile/Company-Profile-PT-Mahkota-Baru-Isolasi.pdf).
It is generated from the same data files as the website (`src/data/*.mjs`), so company info, services
and products stay in sync.

| File | Purpose |
|---|---|
| `build-profile.mjs` | Builds the profile HTML from the site data, then prints it to PDF |
| `company-profile.html` | Generated HTML (open it in a browser to preview) |
| `profile.css` | Print layout and styles of the profile |

To regenerate it after changing content:

```bash
node company-profile/build-profile.mjs
```

This needs Google Chrome, which it runs headless to print the PDF. On macOS it uses the default install
path. Elsewhere, set the path to Chrome, e.g. `CHROME=/usr/bin/google-chrome node company-profile/build-profile.mjs`.

The profile is not part of the website build or the zip download.

## Download as a zip (Apache / any web server)

```bash
npm run zip       # builds the site and writes ./mahkotabaruisolasi-web.zip
```

Unzip it into the web root (e.g. `/var/www/html`, `htdocs`, or cPanel's `public_html`) or into a subfolder.
All links are relative, so it works in either. The zip includes an `.htaccess` (from `src/apache/.htaccess`)
that enables clean URLs (`/isolasi` → `isolasi.html`), compression and browser caching. These need
`AllowOverride All` for that directory and the modules `mod_rewrite`, `mod_deflate` and `mod_expires`.
Without them the site still works, just without those extras.
